# Rust Migration

The backend code has been partly rewritten in Rust, located in the `rust_backend` folder.

To switch to the Rust backend:
1. Navigate to `rust_backend`.
2. Ensure you have Rust installed.
3. Configure `.env` with your database credentials.
4. Run `cargo run`.

The `.NET` backend is still in `Backend/` folder for reference or if you need to rollback.
